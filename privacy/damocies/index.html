    Damocles - 隐私权政策 #

    最后更新日期: 2026年01月01日

    1. 前言 #

    欢迎使用 Damocles 浏览器扩展（以下简称"本扩展"）。我们非常重视您的隐私权。本隐私权政策旨在向您说明本扩展如何收集、使用、存储和保护您的个人信息。使用本扩展即表示您同意本隐私权政策。

    2. 信息收集 #

    本扩展仅收集和使用以下类型的信息：

    2.1 Cookie 信息 #

    本扩展需要访问和处理来自以下域名的 Cookie 信息：

    • keetapp.com 及其子域名
    • sankuai.com 及其子域名

    Cookie 信息仅用于：开发和调试目的，帮助开发者进行 API 测试、环境配置和数据比较，后端不会做任何存储，更不会将 Cookie 信息发送到任何第三方服务器。

    2.2 本地存储数据 #

    本扩展使用浏览器的 storage API 在您的本地设备上存储以下配置信息：

    • 环境配置设置（如：Shepherd, Lion, RDS 等工具的环境参数）
    • 用户界面偏好设置

    2.3 网络请求信息 #

    本扩展使用 declarativeNetRequest 和 proxy 权限，主要用于：

    • 拦截和处理特定的网络请求
    • 在开发环境中代理网络流量
    • 获取 API 响应数据进行比较和分析

    3. 信息使用 #

    我们收集的信息将用于以下目的：

    信息类型 使用目的
    Cookie 信息 身份验证、API 请求授权、调试和测试
    本地存储 保存用户配置、提高使用体验、跨会话保持设置
    网络请求 API 数据获取、接口响应比较、环境巡检

    重要说明：本扩展是 内部开发工具，不涉及商业用途，不会收集任何个人敏感信息（如身份证号、银行账号、密码等）。

    4. 信息存储 #

    4.1 存储位置 #

    所有用户数据均存储在您的浏览器本地存储中，包括：

    • Chrome Storage API（本地存储）
    • 浏览器的 Cookie 存储区域

    4.2 数据共享 #

    我们承诺：

    • 不会将您的任何信息出售给第三方
    • 不会将您的信息用于广告推广
    • 不会将您的信息传输到外部服务器
    • 所有数据仅在您的设备本地处理

    4.3 数据保留 #

    数据将一直保存在您的浏览器本地，直到您：

    • 卸载本扩展
    • 清除浏览器数据
    • 主动清除扩展数据

    5. 信息安全 #

    我们采取适当的安全措施来保护您的信息：

    • 所有数据仅存储在您的本地设备上
    • 不与任何第三方服务器通信
    • 使用浏览器提供的安全存储机制
    • 定期审查和更新安全措施

    请注意：虽然我们采取安全措施，但没有任何互联网传输或存储方法是 100% 安全的。我们无法保证信息的绝对安全。

    6. 用户权利 #

    您对自己的信息享有以下权利：

    • 访问权：您可以随时查看存储在本地的数据
    • 删除权：您可以清除扩展数据或卸载扩展来删除所有信息
    • 修改权：您可以随时修改扩展的配置设置
    • 撤回同意：您可以随时卸载扩展以撤回对信息使用的同意

    7. 第三方服务 #

    本扩展可能与以下第三方域名进行交互，仅用于开发调试目的：

    • keetapp.com - Keeta 内部服务
    • sankuai.com - Sankuai 内部服务
    • localhost - 本地回环地址服务
    • 127.0.0.1 - 本地回环地址服务

    这些第三方服务有自己的隐私政策。我们建议您查看这些服务的隐私政策以了解他们如何处理您的信息。

    8. 儿童隐私 #

    本扩展主要面向开发人员，不面向 13 岁以下儿童。我们不会故意收集 13 岁以下儿童的个人信息。

    9. 政策变更 #

    我们可能会不时更新本隐私权政策。更新后的政策将在本页面发布，并标注更新日期。继续使用本扩展即表示您接受更新后的隐私权政策。

    10. 问题与反馈 #

    联系我们 #

    如果您对本隐私权政策有任何问题、意见或建议，请通过以下方式联系我们：

    • MIS：liwengang03
    • 电子邮件：liwengang03@meituan.com
    • 项目地址：https://dev.sankuai.com/code/repo-detail/~liwengang03/damocles

    我们将在收到您的反馈后尽快回复您。

    11. 适用法律 #

    本隐私权政策受中华人民共和国法律管辖。如本政策之任何规定与法律相抵触，应以法律规定为准。
